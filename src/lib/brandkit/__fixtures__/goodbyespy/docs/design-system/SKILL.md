Quick facts:

- Brand: warm, playful, friendly, retro (50s/60s print advertising). Deep green `#064E3B` on cream `#FFFBF5`. Logo: a spy waving goodbye (`assets/`).
- Type: Besley 700 (Clarendon-slab display, green), Familjen Grotesk (body/UI, 16px), Yellowtail (script — single accent words, tilted), Arima (wordmark only). Loaded from Google Fonts via `styles.css`.
- Link `styles.css` for all tokens; see `tokens/` for the full set (incl. `.gs-halftone`, `.gs-awning`, `.gs-perforation` pattern utilities and `.gs-script`).
- Voice: plainspoken, warm, one wink per page, sentence case, no emoji. Anti-subscription stance ("No subscriptions, no surprises", "Buy a ticket, not a tenancy").
- Signature motifs: poster cards (2px green border + hard 5px offset shadow), starburst seals, ticket-stub pricing with perforations, halftone dots, awning stripes, marquee "goodbye" tickers, ✦ sparkle bullets, dashed underlines.
- Icons: type-first (✦ → ✓ № + Besley numerals); Lucide from CDN only where pictograms are unavoidable.
